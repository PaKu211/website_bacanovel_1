# Phase 11 — Repo hygiene

## What was added
- `.gitignore` expanded with entries for: `static/css/main.css` (compiled CSS), `public/_pagefind/` (Pagefind index), `lncrawl-data/` (scraped data).

## What was removed
- **`node_modules/`** — untracked from git index (was 11,937 files). The directory was in `.gitignore` but had been `git add`ed before the rule existed. The files are regenerated by `npm install`.
- **`lncrawl-data/`** — untracked from git index (was ~2,000+ icon files, sqlite.db, crawler scripts). This is raw lncrawl output, not part of the website. Added to `.gitignore`.
- **`public/`** — untracked from git index (was 927 files). Hugo build output. Already in `.gitignore` but was tracked from an earlier commit.
- **`static/images/rookie-talent-agent-knows-it-all.jpg`** — orphan cover image from the old `rookie-talent-agent-knows-it-all` slug. The cover is now at `static/images/covers/petualangan-dunia-paralel.jpg`.
- **`static/css/main.css`** — compiled CSS artifact. Generated by `npm run build:css` at build time.
- **`.hugo_build.lock`** — Hugo build lock file.
- **`layouts/partials/reading-controls.html`** — dead partial, never referenced from any template after the SPA removal.
- **`layouts/partials/cusdis.html`** — removed in Phase 8, confirmed untracked here.

## What was changed
- `.gitignore`: comprehensive list covering all build artifacts and generated files.

## Why
- AGENTS.md: "Avoid storing generated content in places that make the repo hard to understand."
- `node_modules/` being tracked added 11,937 files to the git history, making clones slow and the repo bloated.
- `public/` being tracked meant every Hugo build produced git diffs — confusing and wasteful.
- `lncrawl-data/` is raw scraper output (sqlite.db, thousands of icon files) that has no place in the website repo.
- The orphan image and dead partials were never used after the SPA removal.
